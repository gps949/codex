# 账号管理界面

[English](ACCOUNT_MANAGER.md) · [使用指南](README.zh-CN.md)

## 打开管理界面

在保存 Codex 账号的主机运行：

```sh
codex account manage
# 只有终端时：
codex account manage --tui --lang zh-CN
# 只打印地址，不自动打开浏览器：
codex account manage --no-open
```

浏览器管理服务是独立进程，需保持运行，Ctrl+C 关闭。同一 `CODEX_HOME` 的 Codex 进程共享账号、选择和额度观测。已经发出的请求保留原身份；修改在后续安全请求边界生效。

默认只监听本机回环地址，端口随机。打印的链接包含浏览器配对码，持有码即可管理账号。配对后地址中的码会被删除，会话保存在按来源隔离的浏览器 session storage 中，不使用 cookie 或 local storage。服务重启后需重新配对。

手机访问可使用 SSH 隧道，或自行配置带身份认证的 HTTPS 反向代理。需要固定端口时：

```sh
codex account manage --listen 127.0.0.1:8765 --no-open
```

将手机或本地端口通过 SSH 转发至主机 8765，使用转发后的端口打开配对链接。监听非回环地址必须明确允许 HTTPS 浏览器来源：

```sh
codex account manage --listen 0.0.0.0:8765 \
  --allow-origin https://codex-accounts.example.com --no-open
```

反向代理需自行配置并保留浏览器 Host。手机打开该 HTTPS 地址，再粘贴主机链接中的配对码。此服务仅提供账号管理，不替代原生 remote app-server 连接。官方手机 `/status` 弹框仍由 App 控制；管理页提供另一个完整账号池视图。

## 看懂状态

订阅账号分别显示登录状态和可用状态。“已登记”“已登录”不代表额度可用。暂留账号和待登录账号也会显示，账号池暂停会单独标注。

额度条表示各账号的**已用**比例。未知额度保留为未知，两个窗口分别显示缓存时间与重置时间。页面每隔几秒读取主机状态，并不生成模型内容、不兑换券，也不持续刷新所有账号凭据。

**Refresh quota** 查询已启用账号的 usage 接口，失败时保留缓存并显示该账号结果。普通额度是参考信息；已收到的额度拒绝，需要新鲜、完整、身份匹配且明确允许使用的后台回复，才能确认恢复。

账号名称和精确 ID 分开显示。没有自定义名称时，完整邮箱作为显示名称；没有邮箱时使用档案 ID。支持按名称、邮箱、ID 搜索，在详情中查看低频信息。桌面是表格，窄屏是卡片。同一邮箱的多个账号仍使用不同的档案 ID。

## 全部耗尽后恢复

已经在其他地方兑换重置券时：

1. 打开管理页，点击 **Refresh quota**。
2. 后台完整回复明确允许同一席位使用时，旧的本地耗尽和额度窗口会被替换。
3. 后台信息不完整时，针对预期账号点击 **Retry after external reset**，允许新请求重新探测；后台仍可拒绝。此操作不花券。

已耗尽的新回合也会进行一次有时间限制的被动额度查询。正在等待恢复的回合会周期查询，可发现外部重置，不必一直等旧缓存截止时间。取消仍可终止等待。这是进程内续跑，关闭主机进程不会持久保存运行中的任务。

同一长任务里，较早用过的账号在冷却结束后可以重新参与选择；曾经耗尽不代表整个任务都不会再使用它。判定全池耗尽前，会做有时间限制的最终恢复检查，覆盖日常小批量检查以外的账号，找到可用的免费额度便停止。当额度元数据说可用、推理请求反复拒绝时，会限制重试，避免无限循环；检查覆盖不完整会明确表示尚未确认，不会当作全池仍然耗尽的证据。

刷新期间出现新的拒绝、重登录或身份变更时，新状态优先；下次新查询可重试。工作区权限或登录故障不会当成普通额度恢复。

在管理页兑换时，打开精确账号的 **Reset credits**，选一张可用券，核对目标后确认。不会先全局切换当前账号。过期和不可用券不能选。断线导致结果不确定时，先刷新额度并检查同一操作，再决定重试；浏览器保留操作 ID，不保留凭据。

**Refresh** 查询；**Retry** 放开本地冷却重新探测；**Redeem** 消费重置券。返回自动订阅模式会保留有效冷却。

## 管理账号与登录

Add account 使用设备码登录。打开验证地址，输入验证码，管理页跟踪完成结果。重新登录会保留已有席位，选错工作区会拒绝覆盖。相同工作区的两个不同 Business 用户保持独立；同一用户和工作区重复添加会刷新已有账号，不新增一个虚假的配额入口。

在同一页面修改名称、优先级、启停调度、移除账号。删除本地凭据时会尝试服务端撤销；本地删除成功不证明远程撤销成功。取消待完成登录会清理实际使用的凭据存储，不撤销已经复制到已有配置档的同一凭据。

**Edit label & priority（修改名称与优先级）**的名称框只展示已保存的自定义名称。留空时自动显示邮箱；仅修改优先级不会把邮箱写成自定义名称，清空已有名称会恢复邮箱。独立终端管理器中，**E** 编辑名称，直接回车保留原名称；**N** 明确清空名称。CLI 可以运行 `codex account set <profile-id> --clear-label`。

独立终端管理器通过编号和明确的操作菜单提供这些功能。无效输入会带说明返回菜单。浏览器对重置券和额度详情展示更充分。

## 选择 Remote Control 主登录

**Host sign-in / Remote Control（主登录 / 远程控制）**面板独立显示主登录来源。在账号详情选择 **Use for host sign-in（用作主登录）**，核对账号、邮箱及完整档案 ID 后确认。终端管理器中选择账号，按 **H** 并输入 `APPLY`。必须先完成订阅账号登录；推理额度正在冷却或被停用调度，不妨碍使用该账号身份作为主登录。

账号池切换推理账号时，该来源保持固定。它引用指定档案的凭据，不会将 token 复制进根目录。首次添加账号池账号不会导入根登录，也不会自动选择主登录身份；没有明确选择时，已有根登录仍是默认主登录来源。

**Use root login（使用根目录登录）**返回 `codex login` 保存的凭据；**Sign out host（退出主登录）**保留账号池凭据和推理选择。对应 CLI 命令：

```sh
codex account primary status
codex account primary use <label-or-email-or-profile-id>
codex account primary root
codex account primary logout
```

当前用作主登录的档案不能直接移除，请先更换来源或退出主登录。升级时会保留已有 `legacy-root` 条目；移除此池条目会保留根登录凭据，新添加账号不再创建自动导入条目。

“已保存可用的主登录信息”是本地状态，不是设备连接成功的证明。官方手机 App 必须使用相同账号和工作区；身份变化后可能需要重连或重新配对。指定登录不可用或变更身份时，主登录认证会停止，不会悄悄换成其他池账号。请修复该登录，或明确选择其他来源。

## API 账号与付费兜底

API 账号独立于订阅池，不参与订阅预热和重置券逻辑。在 **API accounts** 填写提供商 base URL、精确模型、key、上下文窗口和图片能力。key 使用已配置的凭据存储，列表和元数据不含 key。可直接替换 key，不必删账号重加。保存时不会发送生成式兼容探测。

第一版接入要求提供商有**原生 Responses API**。填类似 `https://provider.example/v1` 的 base URL，Codex 自动追加 `/responses`。仅提供 Chat Completions 的接口，包括 Gemini 直接 OpenAI 兼容接口，尚不支持。具备原生 Responses 支持的 DeepSeek 部署可填写其精确地址和模型；工具、模型能力仍因提供商而异，未支持图片时不要启用。

**Use API account** 手动选择后续回合使用的付费目标。**Return to subscriptions** 返回优先使用订阅的自动模式，即使订阅池目前耗尽也能返回。一个回合及其工具续跑绑定同一 API 目标，其他地方修改选择不会中途悄悄换提供商。

付费兜底**默认关闭**。开启时需指定 API 账号、订阅等待上限，并确认计费和对话内容会发送给该提供商。适用的配额耗尽会先尝试订阅恢复及配置允许的用券救援，整个回合共享有限等待预算，再使用明确开启的兜底。登录失败、工作区权限、请求格式错误、不能安全重试不会授权付费兜底；等待取消后不发送兜底请求。

第三方请求不带订阅专用 headers 或其他提供商的加密推理。已完成工具结果保留，不因换提供商重新执行工具。不可移植的压缩历史可能要求新建对话。处理仅改变出站请求，保留本地原始历史。

管理员的登录、提供商、网络、沙箱与审批约束仍然有效。禁用或移除当前 API 目标后，后续选择会不可用，应返回订阅或选择其他已启用 API 账号。

## 面向新手的操作引导

网页概览会根据当前状态给出下一步：添加首个账号、完成登录、刷新已耗尽的订阅、恢复暂停的账号池，或者从付费 API 返回自动订阅。每个账号都有适合其状态的主要操作，高级信息放在详情中。界面默认英文，可以通过语言选择器切换简体中文；账号标签、地址、模型名称和 ID 保持原样。

额度百分比表示已使用比例。0% 和一个重置时间并不能证明额度窗口已启动或 warmup 已完成。缓存时间按照主机时钟解释，异常的未来时间会显示提醒。刷新显示进度和失败摘要，同一账号已有查询时重复点击会复用该查询。后台页面停止轮询；查看状态不会启动模型请求或消耗重置券。

终端管理以编号选择账号、登录任务和重置券，在主菜单等待期间自动显示新验证码。设置提供明确选项，避免拼写配置值。Balanced 和 Longer standby 预设会展示变更预览，启用少量额度的待机预热，保留已有用券和付费 API 授权，不会自动开启额外支出。

重置券操作失败时会保留原操作 ID，刷新额度后可以用同一张券和同一个 ID 重试。关闭终端前请记录打印的操作 ID，结果不明时不要改用新的操作 ID 再次消费。

自动用券或进入付费 API 前，会在有限时间内检查所有符合条件的耗尽席位。已恢复的免费订阅优先；检查失败或覆盖不完整时不会自动支出。等待期间关闭兜底、禁用或删除指定 API 账号会撤销尚未开始的付费请求。已经开始的请求和工具接续仍保持原来捕获的目标。API 的自动压缩和手动 /compact 也使用该 API 的模型与凭据。

## 中英文界面

网页和独立终端账号管理器均默认英文，可选择简体中文：

```sh
# 直接打开中文网页
codex account manage --lang zh-CN
# 打开中文终端管理界面
codex account manage --tui --lang zh-CN
```

网页可使用右上角语言选择器；终端主菜单按 G 可切换。账号名称、邮箱、模型、URL、JSON 键和确认词（如 REDEEM、REMOVE）保持原值，避免切换语言改变操作目标。

## 官方手机 App 内的原生菜单

在 Remote 会话里输入 `/account` 或 `/account manage`；`/account manage zh-CN` 为本次菜单选择中文。原生菜单使用短标题和普通字号的选项说明，每页最多四个账号。打开账号后可以查看额度、刷新、选择账号、外部重置后尝试恢复、启用或停用、改名、重新登录或移除。修改操作会展示目标并要求确认。重置券有独立列表和逐券确认；查询不会消耗券。API 付费使用与最终兜底仍需主动选择。菜单还提供账号池设置、添加订阅账号和更换主登录来源。

如果手机 App 在任务运行时把 `/account manage` 作为 steering 请求发送，主机会打开附着于该任务的非阻塞菜单，不把命令交给模型，也不替换正在运行的任务。fork 无法为官方 App 添加原生工具栏按钮或注册与 `/status` 相同的客户端面板。输出期间是否能打开，仍取决于该 App 版本是否发送 steering 请求并展示非阻塞问答。`/account list` 保留为紧凑文字入口。

用 `/account capabilities zh-CN` 查看此连接声明的界面格式与实际问答响应情况。收到正确响应可以确认协议往返；官方 iOS/Android 是否显示得好、能否正确点击仍需实机确认。超时只表示没有收到回答，不能证明不支持；明确的方法不存在响应才表示此连接没有处理原生问答。仍可用 `/account list` 和 `/account show <label>` 查看。

每个问题 90 秒未回答会关闭，整个菜单最多十分钟。Stop、新消息、断连或取消订阅会取消等待中的问答；关闭附着菜单不会结束真实任务。重连后用 `/account manage` 重新打开。菜单页不写入模型上下文或恢复历史，浏览复用一个简短消息入口，避免每翻一页就刷出一段聊天回复。

现有 WebUI 和完整终端管理器仍独立运行。Remote 不转发它们的网页端口或终端按键。原生菜单使用会话里的问答控件。

## 退出浏览器管理面板

点击 **Stop manager / 停止管理器** 会停止主机监听及全部已配对页面；也可以在启动终端按 Ctrl+C，Unix 主机还支持 SIGTERM。等待中的登录和只读请求会取消，已经开始写入的修改会安全收尾后退出。其他 Codex 会话继续运行。

正常关闭最后一个标签页后，保留 30 秒宽限，方便刷新或重新打开。还有活跃标签页时继续运行。浏览器崩溃或页面完全冻结时，五分钟后租约过期，再进入同样的宽限期。从未打开的管理器十分钟后退出。浏览器本身由操作系统管理。

## 阅读命令行账号列表

`codex account list` 显示的是**已用**额度。`UPDATED` 是显示的额度数据中最老一条的缓存年龄；各窗口准确的记录时间和重置时间可用 `--details` 查看。记录里的重置时间已过时，旧比例会标记为 `stale`，直到新的认证查询确认实际用量。`retry 3h29m` 是本地调度等待，不是已确认的服务器重置时间。列标题按服务器报告的窗口时长显示，时长未知或混合时显示主/次额度窗口。`--show-profile` 可查看完整账号 ID，JSON/TSV 输出保持兼容。

## 即将过期的重置券

普通用户回合期间，主机轮换查询少量订阅账号的认证重置券元数据。券进入 24/18/12/6/3/1 小时阶段时，按当前阶段给出一次被动提醒，每张券最多六次。错过的阶段跳过，重启或同一席位重复档案不会重新计数。提醒不会兑换重置券。很快结束的回合可以填充缓存供下个活跃回合使用，不在已完成的回合里迟到弹出。查看及兑换仍需在独立管理器明确操作；App 内原生菜单也支持查看券列表和明确确认后的兑换。

在 WebUI 或 TUI 内切换语言会保存到主机的非敏感管理器偏好文件，随机端口变化或重启后仍可记住。默认英文，启动语言参数只覆盖本次界面。TUI 输入 **H** 打开主登录管理，输入 **W** 查看各账号预热证据。界面区分保存的登录可用性与运行中宿主、Remote 的实际状态；过期或有歧义的状态回报显示为未知。

网页常用操作直接位于账号行或展开的详情页中。**使用重置券**会优先选择已报告到期日最早的可用券，并直接打开确认页：通常从账号列表到确认使用只需两次点击。确认中展示准确账号、作用范围和到期日，也可点 **换一张券**。如果上次兑换结果尚未确认，会保留原券与原操作编号，不会悄悄改选另一张；未报告到期日的券排在有日期的券之后。保留登录的移出账号池，与移除并删除受管登录，是两个独立操作；legacy-root 始终保留根登录。

## 中断的自动重置

若旧版留下了中断的自动重置操作，管理器会显示“中断的额度重置操作”。请先刷新该账号额度并核对重置历史，再用“归档已复核记录”处理没有账号绑定的旧版记录；终端可按 **J** 进入同一复核流程。归档保留备份并放弃旧请求，之后自动重置可能使用另一张券；本操作不会恢复额度或使用券。新版绑定账号的待确认操作只会在确认额度恢复后自动对账，不能在这里放弃。

## 决策辅助

网页中点 **选择决策服务**；终端主菜单按 **D**。填写提供商和独立令牌即可保存，Cloudflare 只需另外填写 Account ID，无需终端环境变量。保存不联网，**测试连接**仅发送内置示例；开启会将搜索文本和候选说明发送至独立服务，并可能单独收费。参阅[接入说明](DECISION_MODELS.zh-CN.md#在管理界面接入-jev--clef)。
