# 自动选择模型

[English](MODEL_ROUTING_DESIGN.md) · [账号管理](ACCOUNT_MANAGER.zh-CN.md)

自动选模为每个**新任务**或符合条件的**新子代理**选择支持的模型和思考强度，默认关闭。账号轮换、工具排序、技能建议和付费 API 兜底仍是独立设置。

## 从管理界面开始

运行 `codex account manage` 打开浏览器管理器，或运行 `codex account manage --tui` 选择“模型选择”。手机端发送 `/account manage`，在原生菜单中选择“模型选择”。

1. 选择“仅预览”可保留当前模型并观察建议；“自动”会应用符合条件的选择。
2. 设置“决策倾向”：0 偏向更持久，100 偏向更强能力。主任务和子代理可以分别开关。
3. 保存。新的任务读取策略，正在执行的任务保持开始时选定的模型。

建议先使用本地规则，避免分类服务收费或将任务文字传到 Codex 之外。Jev 和 Clef 二选一：先在“决策辅助”中配置一个服务，再在模型选择中选择已配置服务。工具排序可以继续关闭。即使之前已同意工具排序访问服务，任务分类仍需单独同意分享简短任务说明。

服务最多收到 2048 字节 UTF-8 任务文字，不收到会话历史、源文件、账号身份、凭据或额度记录。过长或含糊的任务保留当前模型。超时、服务不可用或返回无效结果时保留当前选择；只有明确开启“本地兜底”才改用本地规则。在管理器中更换服务地址会关闭外部选模，需重新确认任务分享。

“本地模拟”不会请求 Jev/Clef、保存设置或启动推理。候选模型缺失时可明确点击“刷新模型目录”：它只读取所选账号的模型列表，不会兑券或开始推理。

## 命令行

```sh
# 查看保存及实际生效的策略。
codex account routing

# 开启本地自动选择，偏向持久，最高思考强度 high。
codex account routing --mode automatic --source local --preference 25 --max-effort high

# 只对子代理启用。
codex account routing --main-tasks false --subagents true

# 本地模拟，不保存，也不请求 Jev/Clef。
codex account routing --preview 'Translate this short sentence into English.'

# 使用已配置的决策服务，并明确同意分享任务说明。
codex account routing --source decision-service --send-task-description true

# 关闭自动选择。
codex account routing --mode off
```

重复使用 `--allow-model` 可限制具体模型名称；`--all-models` 恢复使用支持的目录。`--role MODEL=economy|balanced|capability` 可以为具体型号指定续航、均衡或能力角色。浏览器和终端管理器也提供候选模型及角色设置。

## 选择规则

- 手动指定模型或思考强度、子代理角色与默认限制优先。完整历史子代理继承父代理模型；恢复的子代理、任务中的补充消息、重试和额度恢复不会重新分类。
- 在终端会话执行 `/model auto`，或在手机模型菜单选择“此会话恢复自动选择”，可解除此会话的手动模型固定；不会修改全局策略或任务分享同意。明确解除后，旧手机客户端回传未改变的模型快照会继续遵循自动策略，选择不同模型则重新固定。API 调用方可以用 `modelSelectionIntent: "explicit"` 或 `thread/settings/update` 固定同一个模型值。
- 候选必须来自当前身份已确认的模型目录，或明确配置的静态目录；内置默认元数据不能证明当前账号有权限。隐藏、专用、元数据不完整或不支持的型号不会被自动选中。
- 模型必须容纳已有上下文与图片，并满足思考强度、服务档位和子代理后端限制。自动选模不会开启 Ultra、改换推理服务商、打开付费 API 兜底或兑券。
- 本地规则需要明确的任务证据；复杂程度和已知风险决定最低角色与思考强度。含糊输入保留当前选择。外部服务只能评估复杂程度，不能指定任意执行模型或批准权限。
- 内置具体型号提供相对的续航／均衡／能力角色；未知型号需要用户明确指定角色。角色及 0–100 倾向**不代表实测订阅额度消耗倍率**。

## 使用边界

切换模型可能影响缓存、模型指令和完成质量；较小模型如果需要更多重试，整个任务未必更省。尚无真实账号基准能证明节省百分比，采用激进倾向前请观察实际完成质量与额度使用。

保存策略、本地模拟和运行时选择是不同状态。管理器的最近记录只反映写出该记录的宿主，不证明每个客户端都已采用策略，也不证明任务已成功完成。官方手机 App 的命令面板行为由其自身决定，fork 无法为闭源 App 增加新的内置工具栏。
